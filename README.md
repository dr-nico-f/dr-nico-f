- [**Smart Light Controller**](https://github.com/dr-nico-f/smart-light-controller) — Local-first CLI, Python library, and FastAPI server for Tuya RGBCW bulbs over the LAN. Python 3.11+, FastAPI, mypy strict, pytest (53 tests). CI across Python 3.11–3.13. [Live demo](https://dr-nico-f.github.io/smart-light-controller/).
